Usage Notes

Do: Use the logo on clean backgrounds with adequate clear space. Maintain the ocean/bone contrast. Use the wave motif as a brand signature element.

Don't: Stretch or distort the logo. Place it on busy backgrounds without a container. Change the wave to a different shape. Use colors outside the palette for the logo.

Minimum size: Icon mark — 24px. Wordmark — 120px wide. Stamp — 40px.

File formats: All assets are SVG (vector, infinite scale). For raster exports, use 300 DPI for print, 72 DPI for web. Export from SVG at the size you need.
